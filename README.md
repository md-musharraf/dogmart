# DOG MART — Premium Pet Store (Dumka)

Modern single-page pet store website with shop filters, cart, dark mode, animations, and WhatsApp ordering.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Build for production

```bash
npm run build
npm run preview
```

Output goes to `dist/` — deploy that folder to any static host.

## Project structure

```
dog mart/
├── index.html          # Main page
├── assets/
│   ├── css/            # Styles (main + features)
│   ├── js/             # Modules (cart, products, animations…)
│   └── data/           # products.json, faq.json
├── package.json
└── vite.config.js
```

## Features

- 16 products with search, category & pet filters, sorting
- Featured product carousel (Swiper)
- Quick view modal, wishlist & cart (localStorage)
- Dark mode, promo bar, page loader
- Pet product finder quiz
- FAQ accordion
- GSAP scroll animations + Lenis smooth scroll
- WhatsApp checkout integration
